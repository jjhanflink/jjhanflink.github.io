GitHub (@jjhanflink) ATS Playwright Repo

TCAD Automation Architecture

1. GDSII Layout Ingestion: Parses multi-layer physical mask coordinates exported from KLayout.

2. Process Deck Synthesis: Translates 2D mask bounds and process steps (spin-coating, UV exposure, etching, deposition, annealing) into parameterized Silvaco Victory Process / Sentaurus `.cmd` scripts.

3. Remote Server Execution: Dispatches jobs over SSH to Linux compute nodes and retrieves `.tdr` structure files for visualization.

ATS Playwright System Architecture

1. Persistent Async Worker Runtime: Runs an isolated background `asyncio` event loop thread so Playwright browser contexts persist across Streamlit UI reruns.

2. Resilient DOM Selector Cascade: Iterates prioritized CSS/ARIA selectors for Greenhouse and standard ATS forms with explicit 10s visibility waits and automatic `set_input_files` PDF resume binding.

3. Human-in-the-Loop Gate & SQLite Ledger: Pauses before final actuation with live viewport screenshots and logs `Draft`, `Queued`, `Submitted`, or `Failed` states to `applications.db`.
